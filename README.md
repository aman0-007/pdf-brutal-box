## ⚡ Features

*   **📁 Merge & Split:** Combine multiple documents (with inline reordering/removal) or extract specific page ranges.
*   **🔄 Page Manager:** Rotate individual pages 90° or delete them entirely via a live thumbnail grid.
*   **🔀 Reorder Pages:** Shuffle page sequences instantly using a fast, native HTML5 drag-and-drop canvas layout.
*   **🖨️ PDF ➔ Image:** Shred PDF pages into high-res PNG/JPG files and download them as a structured `.zip` bundle.
*   **🖼️ Image ➔ PDF:** Batch compile loose images, adjust their sequence, and export them as a single clean PDF.
*   **✍️ E-Signature:** Mobile-responsive drawing pad or PNG upload. Stamp signatures precisely on any corner.
*   **©️ Watermark:** Overlay custom text or transparent images across all document layers.
*   **🗜️ Compress & Clean:** Strip structural bloat and permanently scrub tracking metrics/metadata arrays.
